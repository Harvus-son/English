# English Lab

Учебная платформа по английской грамматике. Навигация организована по схеме **Раздел → Тема 1, Тема 2…**. У каждой темы есть теория с формулами и примерами, короткий оригинальный текст на тему игры/анимации, вопросы на понимание, пересказ из пяти предложений и отдельная контрольная на 15 вопросов.

## Разделы и темы

### Раздел Present
- **Тема 1: Present Simple** — привычки, факты, предпочтения, do/does, don't/doesn't.
- **Тема 2: Present Continuous** — действия сейчас и временные ситуации, am/is/are + V-ing.

### Раздел Построение предложений
- **Тема 1: Построение предложений и WH-вопросы** — порядок слов, утверждения, отрицания, общие вопросы и What/Where/When/Why/Who/Which/Whose/How.

### Раздел Past
- **Тема 1: Past Simple** — завершённые действия, did/didn't, was/were, неправильные глаголы.
- **Тема 2: Past Continuous** — was/were + V-ing, действия в процессе, when/while.

### Раздел Future
- **Тема 1: Future Simple** — will/won't, прогнозы, обещания и решения.
- **Тема 2: Future Continuous** — will be + V-ing для процесса в определённый будущий момент.

### Раздел Perfect
- **Тема 1: Present Perfect** — опыт, результат, have/has + V3, since/for/already/just/yet.
- **Тема 2: Past Perfect** — had + V3 для события, которое произошло раньше другого события в прошлом.
- **Тема 3: Future Perfect** — will have + V3 для завершения к будущему сроку.

Цвета разделов: Present — фиолетово-синий, Past — приглушённый красный, Future — спокойный зелёный, Perfect — мягкий фиолетовый.

## Контрольные и чтение

- Отдельная контрольная на **15 вопросов для каждой грамматической темы**.
- После проверки отображается правильный ответ и пояснение.
- Сюжетные чтения в стиле приключенческих игр, научной фантастики и аниме.
- Пересказ из пяти предложений; есть счётчик предложений.

## Аккаунты и кабинет учителя

Основные файлы для синхронизации прогресса:
- `account.html` — вход и регистрация.
- `teacher.html` — список учеников, результаты и пересказы.
- `course-data.js` / `course.js` — задания и логика проверок.
- `supabase-schema.sql` — таблицы, автоматическое создание профиля и RLS-политики.
- `supabase-config.js` — конфигурация Supabase, в которую нужно внести свой Project URL и anon/publishable key.
- `STUDENT-TRACKING-SETUP.md` — пошаговое подключение.

Чтобы включить работу аккаунтов, нужно настроить свой проект Supabase, выполнить SQL из схемы, зарегистрировать аккаунт и вручную назначить ему роль администратора из SQL Editor. Не вставляй `service_role` key в браузерный код.

## Структура

- `index.html` — направляет в основной каталог.
- `topics.html` — главный каталог разделов.
- `present.html`, `past.html`, `future.html`, `perfect.html` — страницы разделов с нумерованными темами.
- Отдельные страницы каждой темы — `present-simple.html`, `present-continuous.html`, `past-simple.html`, `past-continuous.html`, `future-simple.html`, `future-continuous.html`, `present-perfect.html`, `past-perfect.html`, `future-perfect.html`.

Проект рассчитан на публикацию как статический сайт через GitHub Pages.
