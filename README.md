# English Lab

Адаптивная учебная платформа по английской грамматике. Основные модули содержат теорию, примеры, текст для чтения, вопросы на понимание, пересказ из пяти предложений и интерактивную контрольную на 15 заданий.

## Учебные разделы

- **Present** — Present Simple и Present Continuous.
- **Построение предложений** — порядок слов, отрицания, общие и WH-вопросы: What, Where, When, Why, Who, Which, Whose, How.
- **Past** — Past Simple, did/didn't, was/were, правильные и неправильные глаголы.
- **Future** — Future Simple, will/won't, прогнозы, обещания и планы.
- **Perfect** — Present Perfect, have/has + V3, since/for, already/just/yet; введение в Past Perfect и Future Perfect.

В каждом разделе свой спокойный цвет: Present — исходный фиолетово-синий, Past — приглушённый красный, Future — приглушённый зелёный, Perfect — мягкий фиолетовый. Цвета нужны для ориентации и не используют чрезмерно яркие фоны.

## Как устроен учебный раздел

1. Теория и наглядные грамматические схемы.
2. Оригинальный короткий текст на тему приключенческой игры, фантастики или анимации.
3. Вопросы по прочитанному.
4. Задание написать пересказ ровно из пяти предложений — на странице отображается счётчик предложений.
5. Контрольная из 15 вопросов с мгновенной проверкой и объяснением правильных ответов.

## Аккаунты и учительская панель

Страницы `account.html` и `teacher.html` подготовлены для Supabase Auth + PostgreSQL. Без подключения Supabase уроки по-прежнему работают, но прогресс хранится только в текущем браузере.

Чтобы включить аккаунты и общую базу:
1. Выполни `supabase-schema.sql` в SQL Editor своего проекта Supabase.
2. Внеси Supabase Project URL и anon/publishable key в `supabase-config.js` (не используй service_role key).
3. Зарегистрируй свой аккаунт через `account.html`.
4. Назначь аккаунту роль администратора по инструкции из [STUDENT-TRACKING-SETUP.md](https://github.com/Harvus-son/English/blob/main/STUDENT-TRACKING-SETUP.md).
5. Ученики регистрируются на `account.html`; результаты тестов попадают в `quiz_results`, пересказы — в `writing_submissions`.

Таблицы используют Row Level Security: ученики могут создавать и читать только собственные записи, учитель с ролью `teacher` или `admin` может просматривать все результаты и работы.

## Основные файлы

- `topics.html` — каталог учебных разделов.
- `present.html`, `past.html`, `future.html`, `perfect.html` — грамматические разделы.
- `sentence-builder.html` — отдельный модуль по грамматике предложений и WH-вопросам.
- `course-data.js` — 75 вопросов для пяти контрольных.
- `course.js` — общая логика тестов и сохранения пересказов.
- `supabase-schema.sql` — структура БД и RLS-политики.
- `STUDENT-TRACKING-SETUP.md` — подключение аккаунтов и кабинета учителя.

Сайт можно публиковать через GitHub Pages как статическое веб-приложение.
