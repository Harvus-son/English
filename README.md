# English Lab

Самостоятельное веб-приложение для обучения английскому языку.

## Урок 01 — Present Simple + Daily Life

Расчётная продолжительность: **около 60 минут**.

### Структура урока

**Information**
- цели урока;
- когда используется Present Simple;
- привычки, регулярные действия, факты и предпочтения;
- утверждения;
- He / She / It + -s;
- основные правила написания -s / -es / -ies;
- отрицания don't / doesn't;
- вопросы Do / Does;
- короткие ответы;
- визуальные схемы;
- короткий текст для Reading;
- вопросы по тексту;
- словарь Daily Life с примерами.

**Practice**
- 8 интерактивных заданий;
- повторная попытка после ошибки;
- мгновенная обратная связь;
- XP только за правильные ответы;
- прогресс сохраняется в браузере.

**Self Work**
- исправление ошибок;
- письменный рассказ о своём дне;
- сохранение письменной работы;
- вопросы для устной практики;
- ответы доступны после самостоятельной попытки.

**Progress**
- XP;
- процент выполнения практики;
- список освоенных элементов.

## Запуск

Проект является обычным статическим веб-приложением и может работать через GitHub Pages.

Для локального запуска с Node.js:

    npm install
    npm start

Затем открыть http://localhost:3000.
