# Подключение аккаунтов и кабинета учителя

Для этого проекта используется Supabase Auth + Postgres. Пока проект Supabase не привязан, регистрация и синхронизация будут отключены; статические HTML-уроки при этом работают.

## 1. Создай проект Supabase
1. Открой https://supabase.com/dashboard и создай проект.
2. В **SQL Editor** открой файл `supabase-schema.sql` из этого репозитория, вставь весь SQL и запусти его.
3. В Project Settings → API скопируй Project URL и anon/publishable key.
4. В `supabase-config.js` замени `YOUR_SUPABASE_PROJECT_URL` и `YOUR_SUPABASE_ANON_OR_PUBLISHABLE_KEY` своими значениями. **Не используй service_role key** в браузере.
5. В Authentication → URL Configuration укажи URL своего GitHub Pages сайта как Site URL. Для тестирования можно отключить подтверждение email, но для реального использования лучше оставить подтверждение включённым.

## 2. Создай свой аккаунт учителя
1. Открой страницу `account.html` на опубликованном сайте и зарегистрируйся на свой email.
2. В Supabase → SQL Editor выполни команду ниже, заменив email на тот, с которым зарегистрировался:

```sql
update public.student_profiles
set role = 'admin'
where lower(email) = lower('YOUR_EMAIL');
```

3. Выйди и войди снова. Затем открой `teacher.html`. Панель доступна только аккаунтам с ролью `admin` или `teacher` в таблице.
4. Ученики регистрируются через `account.html`. После входа их контрольные сохраняются в `quiz_results`, а пересказы — в `writing_submissions`. Учитель увидит их в панели.

## 3. Что хранится
- Email и отображаемое имя профиля.
- Название раздела, балл, процент и выбранные ответы по контрольным.
- Отправленные учеником письменные пересказы и время отправки.

Таблицы защищены Row Level Security: ученик читает только свои результаты и может добавлять записи только от своего ID; преподаватель может просматривать записи всех учеников. Роль нельзя назначить через форму регистрации — повысить пользователя может только владелец базы через SQL Editor.

## Важно
Я не создавал пароль и не активировал реальный аккаунт от вашего имени: для этого нужен ваш email и доступ к конкретному проекту Supabase. Файлы уже подготовлены; после настройки URL и ключа и выполнения SQL регистрация и мониторинг будут работать. Не публикуй service_role key, пароль базы или учётные данные от своего аккаунта.
